# Student Performance Prediction Using MLP

A Deep Learning project that predicts students' final mathematics grades using a **Multilayer Perceptron (MLP)** neural network.

## Objectives
- Analyze student performance data.
- Preprocess data for deep learning.
- Predict final grades using an MLP regression model.
- Classify students into Low, Medium, and High grade categories.
- Evaluate performance using metrics and visualizations.

## Technologies Used
- Python
- Google Colab
- Pandas, NumPy
- TensorFlow / Keras
- Scikit-learn
- Matplotlib, Seaborn

## Dataset
**UCI Student Performance Dataset** — `student-mat.csv`

The dataset contains 395 student records and 33 original columns.

[View Dataset](https://archive.ics.uci.edu/dataset/320/student+performance)

## Results

**MLP Regression**
- MAE: 1.93
- MSE: 7.22
- RMSE: 2.69
- R² Score: 0.648

**MLP Classification**
- Accuracy: 77.22%
- Grade categories: Low (0–9), Medium (10–14), High (15–20)

The project includes training graphs, prediction comparisons, a confusion matrix, and classification metrics.

## How to Run
1. Open `DL_ASS2.ipynb` in Google Colab.
2. Upload `student-mat.csv` when required.
3. Run the notebook cells in order.
